## History design delivered in this stage

Runs now occupies a dedicated, centered workspace. It temporarily hides surrounding file/change panes and the composer without changing pane preferences or destroying the draft. Returning to Chat restores them.

The workspace offers search over loaded Codex titles and opening messages, filters for attention/running/plans/completed, factual counts, an attention group, and local-calendar date groups. Unknown outcomes remain unknown. Search is explicitly scoped to loaded conversations; older pages load only through an explicit action. No repository scan, new history database, timer, or model call is introduced.

Rows show the Codex title, opening context when distinct, recency, known model, actual status, and current-conversation identification. Earlier tasks are placed under a labeled disclosure for the selected conversation instead of an unrelated-looking list of IDs. History failures preserve loaded rows, explain the error, and offer retry. A failed initial request does not masquerade as an empty project. In-flight request identity prevents an old project response from changing the current history loading state.

Keyboard users can focus conversation search with Command/Ctrl-F, choose filters, and open rows with native buttons. Filtering does not send requests or resume threads. Leaving Runs preserves drafts and pane preferences. Live events can move a row out of a filter without a refresh.

## Project navigation delivered

The project picker is now a native HTML dialog. It searches only known recent project paths, exposes the exact path for duplicate folder names, marks the current project, and supports arrows/Enter, Escape, backdrop dismissal, and focus return. Selecting the current project simply closes the dialog rather than reopening the workspace. Global navigation shortcuts do not operate behind it.

When tasks are active, switching options explain the restriction without interrupting work. When manual edits are dirty, the existing save/discard/cancel flow remains authoritative. A cancelled switch preserves the dirty buffer. If the selected directory is unavailable, the current project and saved editor contents remain usable and the actual error is shown. Screenshots `project-switcher-dark.png` and `project-switcher-light.png` were inspected at 1000 × 650. Both appearances passed the scoped axe audit.
