# Visual refresh and density pass — September 28

Direction chosen with the user: a bolder visual refresh, compact pro-tool density, structural changes allowed, with priority on following a task and juggling tasks/history.

## Survey findings addressed

- Too little transcript at laptop size: a breadcrumb bar, a separate task header, a two-row completion card, and a two-row composer stacked up. At 1000 × 650 only ~200 px of conversation was visible.
- Duplicate status ("Waiting for you" appeared three times; "Task completed" twice), always-visible Copy/Quote on every message, repeated avatar + name on consecutive replies.
- Raw values in the UI: `inProgress`, `completed`, `Modified 1 file(s)`, `codexAccount`, `sleeping`, `WORKSPACE / TASK`.
- Empty inspector and a disabled composer shown with no project; a composer on Settings.
- History rows ~135 px tall, with a separate always-visible Pin/Rename/Archive line; launcher timestamps with seconds.
- ~24 ad-hoc font sizes (many 9–10 px), no spacing/radius tokens, and a single mint accent used for both interaction and success.

## Changes

- **Tokens:** graphite surfaces, an indigo interaction accent separate from green/amber/red status colors, a 7-step type scale (minimum 11 px), radius and elevation tokens, and a matching light theme. Hard-coded status tints now derive from tokens.
- **Shell:** 48 px top bar, segmented primary navigation, a status pill, a Tasks switcher with a live running count, a filled amber attention button, and New task as the primary action. The inspector hides when no project is open; the explorer and composer are hidden on Settings.
- **Chat:** the task title, state pill, duration/details popover, and pane controls share one row. Completion is a single line with a checks/files summary popover. Consecutive agent replies are grouped; message actions appear on hover or keyboard focus; user messages are compact right-aligned bubbles. Activity rows show readable states ("Running", "Edited 2 files") and a rotating chevron.
- **Composer:** one control row with Queue next / Stop / Send together; ⌘↵ in the placeholder; while a task runs the placeholder says it will steer; 48 px resting height; a clear disabled Send.
- **History and launcher:** single-line rows (status icon, title + preview, model, status, relative time), actions revealed on row hover or focus without invisible click targets, and tighter filters. The launcher shows status + relative time for tasks and drops the filler taglines. `relativeTime` has a unit test.
- **Settings and session panel:** plain-language connection state, bordered secondary buttons, and fixed Speed section spacing.

## Validation

- Svelte check: 0 errors or warnings. Prettier: passed. Vitest: 18 passed.
- Playwright Chromium and WebKit: 80/80 each, including the axe audit (16 states, dark and light) with `WORKBENCH_AXE_PATH` set. Contrast fixes were needed for light-mode diff green/red and dark muted text.
- Updated test expectations for intentional changes only: top bar height (48), `Stop` label, `In progress` casing, the new placeholder, and hovering a History row before its actions.
- No Rust, protocol, timers, or background work changed.
