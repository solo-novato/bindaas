# Project history

These documents record how the app was originally specified and built, before it was open-sourced and renamed from its working title, "Codex Workbench", to **Bindaas**. They are kept for context: design intent, trade-offs, and validation notes. They may describe behavior that has since changed; the code and the top-level README are authoritative.

- `PRODUCT.md`, `UX_SPEC.md`, `IMPLEMENTATION_GUARDRAILS.md`, `HANDOFF_README.md`, `BUILD_PROMPT.md` — the original specification pack used to build v1 with a coding agent.
- `VALIDATION.md` — validation notes from the initial build.
- `build-logs/` — dated UX review, redesign, motion, and usability passes.

Current architecture notes live in [`../architecture/`](../architecture/).
